# Бот заявок для мастерской (замки)

Простой Telegram-бот:
- вы (владелец) создаёте заявку — адрес + описание проблемы;
- бот рассылает заявку всем сотрудникам;
- сотрудник берёт заявку в работу;
- после выполнения сотрудник заполняет отчёт — стоимость, расходы, итог, комментарий;
- всё сохраняется в базу (SQLite), доступен отчёт за день/неделю/месяц.

## 1. Получить токен бота

1. В Telegram напишите @BotFather
2. Команда `/newbot`, придумайте имя и username
3. Скопируйте выданный токен

## 2. Узнать свой Telegram ID

Напишите в Telegram боту @userinfobot — он пришлёт ваш ID числом.
Это и будет `OWNER_ID`.

## 3. Настройка

1. Скопируйте `.env.example` в `.env`:
   ```
   cp .env.example .env
   ```
2. Откройте `.env` и впишите:
   ```
   BOT_TOKEN=токен_от_BotFather
   OWNER_ID=ваш_telegram_id
   ```

## 4. Установка и запуск

Нужен Python 3.10+.

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Бот запущен и работает, пока запущен процесс. Для постоянной работы на сервере
разместите его на VPS и запускайте через systemd или screen/tmux, либо через
pm2 / supervisor.

Пример systemd-юнита (`/etc/systemd/system/lockbot.service`):

```ini
[Unit]
Description=Lockbot Telegram Bot
After=network.target

[Service]
WorkingDirectory=/путь/к/lockbot
ExecStart=/путь/к/lockbot/venv/bin/python main.py
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
```

Затем:
```bash
sudo systemctl daemon-reload
sudo systemctl enable lockbot
sudo systemctl start lockbot
```

## 5. Как пользоваться

### Добавление сотрудников
1. Сотрудник открывает бота и пишет `/start` — бот присылает ему его Telegram ID.
2. Сотрудник передаёт этот ID вам.
3. Вы пишете боту `/add_worker`, вводите ID, затем имя сотрудника.

Список сотрудников: `/workers`
Удалить сотрудника: `/del_worker <ID>`

### Создание заявки (только вы, владелец)
`/new` → бот спросит адрес → затем проблему с замком → заявка уходит всем сотрудникам с кнопкой «Взять в работу».

### Работа сотрудника
1. Получает заявку, нажимает «🔧 Взять в работу» (первый успевший — берёт, остальным сообщение обновится).
2. После выполнения нажимает «✅ Завершить и сдать отчёт».
3. Бот по очереди спрашивает: стоимость → расходы → комментарий (можно "-" чтобы пропустить).
4. Итог (прибыль = стоимость − расходы) автоматически сохраняется, вам приходит уведомление.

### Отчёты (только вы)
`/orders` — список активных (не завершённых) заявок.
`/report` — выбираете период (сегодня / неделя / месяц), бот присылает список выполненных заявок и суммы: общая стоимость, расходы, чистая прибыль.

## Структура проекта

```
lockbot/
├── main.py          — точка входа, запуск бота
├── config.py         — загрузка токена и ID из .env
├── db.py             — работа с базой данных SQLite
├── states.py          — состояния диалогов (FSM)
├── keyboards.py       — inline-кнопки
├── owner.py           — команды для владельца
├── worker.py          — команды/сценарии для сотрудников
├── requirements.txt
└── .env.example
```

## Возможные доработки (по запросу)
- Выгрузка отчёта в Excel-файл вместо текста в чате.
- Несколько филиалов/направлений заявок.
- Фото до/после работы, прикрепляемые к заявке.
- Учёт рабочего времени сотрудника.
